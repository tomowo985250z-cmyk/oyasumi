# 屋根の寝そべり猫

全16猫種、各1枚のRGBA透過PNG。三毛猫は承認済みの試作と同一の画像。残り15種は、その姿勢と各猫種の既存座り画像を参照し、built-in imagegenで制作した。画像を編集・上書きせず、生成されたalphaをそのまま保持している。

制作プロンプトは `prompts.json`。SHA-256・サイズ・接地用の透明余白は `manifest.json`。

画像を更新した場合は `node test-support/roof-recline/build-metadata.cjs`、続けて `npm run release` で接地データと公開用ハッシュを更新する。

ホームの屋根専用。各表示枠が4夜に1回寝そべるため、混在率は25％。同じ夜の再表示では姿勢を維持し、最大3匹のうち寝そべりは最大1匹。猫種・人数の算出、猫部屋・投稿・食事・DBを維持する。

試作と同じサイズ（寝そべり78px、3匹時70px、座り52.02px）と間隔を維持。前足・胴体の接地を整えるため、寝そべりだけ試作から屋根の座標で1px下へ調整した。
