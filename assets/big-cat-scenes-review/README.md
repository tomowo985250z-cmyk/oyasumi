# Big Cat Morning, Day And Night Scenes

The contact sheet is ordered snow leopard, leopard, cheetah, jaguar by row.
Columns: waking, relax, play, groom, doze, gaze, sleeping.

28 separate 1254 x 1254 RGBA PNG assets live in `../sleep-wake-cats/`
and `../day-cats/`, following the existing scene filenames. The application
uses the same timing, sizes and actions as existing cats. The approved six
profile expressions in `../big-cats/` are unchanged.

`prompts.json` records each generated asset and its references. The temporary
reference montage combined existing domestic/wild scenes with approved calm
large-cat faces; it was used only for generation and is not an app asset.
