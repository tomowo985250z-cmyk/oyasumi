# 夜の仕草

採用済みの三毛猫試作3枚をそのまま使用し、残り15猫種に各3姿勢を展開した透過PNG。既存の座り・昼・就寝・給餌・屋根猫の画像は置換しない。

- `*-curl.png`：クッションで丸くなる。
- `*-stretch.png`：ラグで前足を伸ばす。
- `*-window.png`：窓台で寝そべり、月の方を眺める。表示時に左右反転と6度の回転を適用。

生成方式は組み込みの `image_gen`。猫種の既存 `assets/cat-refresh-v1/{coat}/morning.png` を毛色・体格・画風の参照、採用済み三毛猫を姿勢の参照として使用。生成されたPNGの画素・アルファは加工していない。生成プロンプトは `prompts.json`、元ファイルと採用先の対応は `provenance.json`。

`manifest.json` は各PNGのSHA-256、寸法、アルファ128以上の輪郭、表示位置を記録。400×330の部屋座標で丸くなる猫の下端251、伸びの前足277、窓辺の足・お腹161を基準とする。`test-support/build-night-gesture-metadata.cjs` で読み取り解析して再生成する。

`NightCats` はJST18:00〜06:00の起きている自分の猫に適用。15分枠をユーザーID・夜の日付から安定して選び、5枠で座り2回・その他各1回（40/20/20/20）。同じ枠では再読み込み・画面遷移・猫種変更で仕草は変わらず、午前0時にも夜の基準をリセットしない。就寝済みは既存表示を優先する。DBや保存データは追加しない。
