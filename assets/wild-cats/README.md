# 野生猫の切り出し素材

利用者が添付した昼行動画像（1536×1024）と表情画像（1254×1254）から、PNGとして44個を切り出しました。画像の再生成・描き直しはしていません。円の外側は透過し、元画像の背景と猫はそのまま使用しています。

- 行：マヌルネコ、スナネコ、クロアシネコ、スナドリネコ。
- 昼の列：relax（座る）、play、groom、doze、gaze。画像内の中心Xは303／572／838／1108／1384、中心Yは234／443／650／870。230px角の切り出し。
- 表情の列：calm、sleepy、yawn、restless、happy、surprised。中心Xは226／409／592／776／961／1145、中心Yは250／507／764／1023。190px角の切り出し。
- 就寝は昼のdoze、起床は表情のhappyを使用。昼行動の時間帯・2時間ごとの切替は既存の `DayCats.current` をそのまま使用。
- `prepare-release.js` が素材のハッシュを `wild-cat-assets.js` に反映します。

Supabaseへの保存には `supabase/wild-cats.sql` の事前確認と適用が必要です。元の8毛色、既存データ、RLS、表情RPC、投稿RPCは変更しません。
