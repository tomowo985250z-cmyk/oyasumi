## 加工と再生

両端を各1秒取り除き、モノラル16kHzへ変換。130Hzのハイパス、5.6kHzのローパス、12msの先読みピーク抑制（復帰200ms）で低い風の響きや鋭い破裂音を抑えました。会話・音楽などの合成音の追加や時間引き伸ばしはしていません。末尾と冒頭を6秒の等電力クロスフェードで事前に接続し、MP3のエンコーダー遅延を測定してループ範囲から除外しています。

配布ファイル `campfire-recorded.mp3` は **1,558,224バイト（約1.56MB）**、モノラル48kbps。1周期は約259.61秒（4分19.61秒）で、短い断片の反復ではありません。停止後の再開時だけ開始位置をランダム化し、再生速度や音程は変えません。

焚き火ON時のみ同一サイトから取得し、ブラウザーキャッシュを利用。ページ内では取得・デコードを共有し、通常は16kHzモノラルの約16.62MBのPCMバッファ1つを再利用します。再生中のJSタイマー・短い合成音の再生成はありません。旧来の自然音マスター音量、焚き火の個別ON/OFF、画面・非表示時の制御を使います。旧合成音よりRMSは数dB控えめ、ピークは約-11.04dBFSで、急な大音量を避けています。

初回は読込・デコード後にフェードイン。取得失敗時は合成音へ差し戻さず無音とし、自動再試行は60秒以上空けます。通信失敗中の再生開始は保証できません。2回目以降もブラウザーがキャッシュを破棄した場合は再取得します。

## 確認の範囲

録音内容は公開元の説明を参考に選定しました。波形・音量・デコード・接続・操作を技術的に検証しますが、独立した聴感確認とiPhone実機試聴は未実施です。会話・風切り音・音楽等が全編にわたって含まれないことを聴取で確認した、という意味ではありません。`fuel.webp` と庭・猫・炎・鹿威しの表示は変更していません。
