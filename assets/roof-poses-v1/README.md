# 屋根猫：正式採用の座り姿2種類

現行の座り16毛色・伏せ16毛色と、保存されている旧7パターンを比較したうえで追加。
ユーザーの変更指示に従い、追加は2種類のみ。立ち姿・伸び姿は不採用。

- 三毛：香箱座り。四肢を胴の下に収め、既存の前脚を伸ばした伏せと区別。
- グレー：横座り。腰を横へ落とし、後脚を片側へまとめ、尾は反対側へ。

現状の座り猫を直接参照し、丸い体格と頭身を維持。全員が後ろを向き、同じ方向の空を眺める。
生成は組み込み image_gen、1枚ずつ。既存画像の上書きや塗り替えなし。
生成プロンプトは `prompts.json`。生成原本・比較画像はローカルの `output/roof-poses-v1/` に保管し、配信用ファイルには含めない。

配信用は長辺384pxの透過WebP。原画は改変せず、縮小・形式変換のみ。
2枚合計27,242 bytes。各画像の寸法・接地位置・SHA-256は manifest.json に記録。
形式変換の記録：ローカルの `output/roof-poses-v1/package.cjs`（Playwrightを使用）。

該当毛色の既存4夜周期のうち1夜だけ座りの変化を追加。毛色抽選・伏せの25%周期は維持。
別の毛色への代用なし。表示または2分以内の登場に必要な画像だけ読み込み、既存の一括decode確認を通す。
画像・DOM要素の数、タイマー、アニメーション、CSSフィルターは追加しない。
既存猫の画像・サイズ、屋根以外の猫や機能は変更しない。

ユーザー承認により、この2種類を正式採用。

ローカル検証済み：Edge / WebKit の375・390px、2種類とも実際に登場する夜の描画・接地・画面切替・同一tickのDOM安定性。
896レイアウトで毛色・従来サイズ・伏せ周期・間隔を検証し、既存39画像のSHA-256一致を確認。
既存の読み込み検証（両ブラウザーの320・375px）も通過：HTTPキャッシュ、戻る操作、再読み込み、古いdecodeの排除、読み込み失敗時の非表示・復帰。
実際のローカル開発サーバーでも2画像のHTTP 200・WebP MIME・配信内容のハッシュを確認。

最終確認：`node test-support/roof-poses/verify.cjs [--edge] [--published]`。
四季×昼・夕方・夜×375/390pxで、夜の両姿勢のアルファ接地、接触影、画像由来の投影、既存と同じ環境光フィルターを確認する。昼間は従来どおり屋根猫を表示しない。
