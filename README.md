# おやすみ

眠れない夜に「まだ寝れない…」「もう寝るよ」を伝える、スマホ優先のフロントエンド初期版です。添付見本の濃紺・月・淡い青とピンクのボタンを参考にしています。

## 起動

`index.html` をブラウザで開くと操作できます。安定した端末内保存には Node.js 22以上で `npm start` を実行し、http://localhost:3000 を開いてください。

## 実装済み

- 投稿は「まだ寝れない…」「もう寝るよ 🌙」「眠れないけど寝てみる 💤」「お先に寝ます 👋」の4つから選択。寝る報告は1タップでおやすみ完了画面へ
- 時刻付きタイムライン、投稿の絞り込み、自分の投稿削除
- リアクションは「おやすみ 🌙」「いい夢を 💤」「また明日 👋」の3つから選択（1投稿につき1つ、再度押すと解除、別の選択肢で変更）
- おやすみ完了画面、翌朝のおはよう記録、プロフィールの記録
- ニックネームのみ自由入力（1〜12文字、連絡先・明らかに不適切な表現は禁止、理由を短く表示）、ダークモード切り替え
- 端末内保存、iPhoneのセーフエリア、キーボード操作、動きを減らす設定への配慮

他人への投稿・リアクションは選択式のみです。自由メッセージ・DM・個別チャット・フォロー機能はありません。既存の投稿は引き継ぎ、旧リアクションは「おやすみ」に移行します。有効な保存済みニックネームも保持します。保存済みの名前が新しい入力ルールに違反する場合は、名前だけを「ともを」に戻し、投稿・リアクション・朝の記録・表示設定は保持します。

ニックネームは前後の空白を除き、書記素単位（絵文字も見た目の1文字）で1〜12文字を判定します。全角文字などをチェック時に正規化し、URL・メール・一般的な電話番号、暴言・差別語・性的な表現の簡易ルールに合致する名前を拒否します。表示はHTMLエスケープします。これはフロント側の最低限のチェックで、すべての不適切表現や迂回表記を検出するものではありません。バックエンド導入時には同じ検証をサーバー側でも行う必要があります。

他のユーザー・人数・グラフはサンプルです。バックエンド、ユーザー認証、端末間共有、プッシュ通知は未実装です。実際に人同士で投稿を共有するには、今後バックエンドが必要です。

## 動作確認

Node.js 22以上とMicrosoft Edgeを用意し、`npm test` を実行してください。追加パッケージは不要です。4種類の投稿、3種類のリアクション、保存、旧データの移行、翌朝の記録、ニックネームの入力検証・エラー表示・キャンセル・保存、名前以外に自由入力欄がないこと、画面幅を検証します。Windows以外では `EDGE_PATH` 環境変数にChromium系ブラウザの実行ファイルを指定してください。
