# おやすみ

眠れない夜に「まだ寝れない…」「もう寝るよ」を伝える、スマホ優先のフロントエンド初期版です。添付見本の濃紺・月・淡い青とピンクのボタンを参考にしています。

## 起動

`index.html` をブラウザで開くと操作できます。安定した端末内保存には Node.js 22以上で `npm start` を実行し、http://localhost:3000 を開いてください。

## 実装済み

- 状態投稿、時刻付きタイムライン、投稿の絞り込み、自分の投稿削除
- 「おやすみ」「わかる」のリアクション（再度押すと解除）
- おやすみ完了画面、翌朝のおはよう記録、プロフィールの記録
- ニックネーム変更、ダークモード切り替え
- 端末内保存、iPhoneのセーフエリア、キーボード操作、動きを減らす設定への配慮

他のユーザー・人数・グラフはサンプルです。バックエンド、ユーザー認証、端末間共有、プッシュ通知は未実装です。実際に人同士で投稿を共有するには、今後バックエンドが必要です。

## 動作確認

Node.js 22以上とMicrosoft Edgeを用意し、`npm test` を実行してください。追加パッケージは不要です。モバイルサイズで投稿、リアクション、保存、翌朝の記録、名前の安全な表示、横幅を検証します。Windows以外では `EDGE_PATH` 環境変数にChromium系ブラウザの実行ファイルを指定してください。
