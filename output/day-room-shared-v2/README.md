# 昼猫の部屋・共通デザイン比較

正式基準は [DAY-ROOM-DESIGN.md](../../DAY-ROOM-DESIGN.md)。基準の4場面と、アプリのホーム・マイページ・他人のプロフィールを比較するローカル画面です。

起動:

```powershell
node output/day-room-shared-v2/serve.cjs
```

http://127.0.0.1:9412/ を開きます。NodeがPATHにない環境では `./output/node-tools/node.exe` を使えます。

場面・猫16種・四季・天気・JST日時・10種類の画面幅・明るい表示を切り替えられます。「アプリ全体を開く」で実際の画面構成と操作も確認できます。マイページのごはん・他人のプロフィールのおやつは既存の保存処理と約6秒の演出を使い、同じ部屋内で再生します。「食事の試行回数を戻す」はこのプレビューのデータだけをリセットします。

本番SDK・接続設定・更新クライアントはプレビュー応答から除き、外部接続をCSPでも制限しています。既存の食事SQLをメモリ内PGliteに読み込み、終了時に試行データを破棄します。

検証:

```powershell
node output/day-room-shared-v2/check.cjs
```

WebKitで320〜440pxの10幅、4場面、ホーム・マイページ・他人と自分の公開プロフィール、猫16種、四季×天気を確認します。食事は保存確認・約6秒再生・二重表示防止・留守からの復帰・夜・動きを減らす設定・18:00境界を確認します。`report.json` と比較スクリーンショットを同じフォルダへ出力します。iPhone実機の検証ではありません。

食事ボタンは44px以上のタッチ領域を確認し、WebKitのタップで操作します。06:00・12:00・18:00の直前と直後、食事中の18:00切り替え、7日制限の一時解除が表示されることも確認します。本番の制限解除設定は変更しません。

`--review-only` を付けると、18:00境界と比較画面の操作だけを確認し、結果を `review-report.json` に保存します。WebKitは `output/webkit-tools/core/package` に配置したローカルツールを利用します。Node・ブラウザの実行ファイルはリポジトリに含めません。
