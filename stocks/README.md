# 4画面の株式モニター

`stocks/`にCanBas・クリングル・Joby・ヒートマップを配置。上部タブ、左右スワイプ、ヒートマップのタップで切替。3社の既存ページは同一オリジンのiframeで表示し、既存ファイル・URL・更新処理を変更しない。赤／緑のテーマは埋め込み時だけ適用する。縦スクロールは各社の長い情報ページ内に残し、ヒートマップは縦スクロールなしで表示する。

株数は既存の`oyasumi:portfolio:v1:<symbol>`から読む。取得単価を使わず、現在の円建て株価×株数で時価評価額を計算。Jobyは既存のUSD株価×現在USD/JPY、騰落率は既存の円建て比較関数を再利用する。入力値を外部送信せず、このページ独自の保有データを保存しない。

未入力・0・無効値は除外。全銘柄が未保有なら3社を均等表示し、評価額は未入力として表示。価格未取得の保有銘柄がある場合は、構成比未算出と明示して保有銘柄を仮の均等面積で表示する。取得失敗時は直前の正常データを保持して古い参考値と明記する。

タイルの幾何面積は時価構成比に厳密に比例する。極小銘柄の面積を水増ししない。文字が収まらない場合は下部のタップ可能な補助表示に銘柄・騰落率・評価額を併記する。動的ビューポートと四辺のsafe-areaに対応する。

統合画面内の株価は3社とも40px・円記号に統一。タイル文字は面積・縦横寸法・実際の文字幅に応じて拡縮し、収まらない場合は評価額→騰落率の順に補助表示へ移す。銘柄名を優先し、極小の場合は全項目を補助表示で読めるようにする。タブ・スワイプ・タイルで切り替えた画面は、表示後にスクロール位置を0へ戻す。初回のデータ読込完了後も位置を確認する。

検証：`node --test stocks/*.test.mjs`。既存の公開JSONを読むだけなので新しい取得ActionsやAPI設定は不要。
