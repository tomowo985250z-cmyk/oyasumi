# 3社統合モニター

`stocks/`にキャンバス・クリングル・Jobyの3画面を配置。各社の既存モニターを同一オリジンのiframeで表示し、上部タブ・左右スワイプ・キーボードで切り替える。各社の個別URL、臨床試験・承認・認証・ニュースの更新、変更マーク・変更履歴は維持する。

画面切替後は最上部へ戻し、各ページ内では縦スクロールできる。横方向は10pxから方向を判定し、横成分が縦の1.2倍を超える24pxの移動で切り替える。先に縦へ動いた操作は縦スクロールを優先する。180msの切替アニメーションと重複切替防止を維持し、動きを減らす設定ではアニメーションを省略する。入力・選択・ボタンの通常操作を妨げない。

株価・前日比・為替・保有入力・損益・ヒートマップは廃止。旧保有入力の3銘柄専用localStorageキーだけを次回表示時に消去し、おやすみ本体の保存データは変更しない。価格取得・保存・公開を行わず、各社モニターの公開情報のみ読み込む。過去データの確認結果は[削除記録](./REMOVAL.md)を参照。

検証：`node stocks/browser.cjs`。Playwright WebKitで320/375/390/430px、3画面切替・縦スクロール・既存監視情報・金額UIと価格通信の不在を確認する。
