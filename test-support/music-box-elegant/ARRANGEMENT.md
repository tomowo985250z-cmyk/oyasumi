# 全5曲の独自オルゴール編曲（v13）

現行の月の光、G線上のアリア、ノクターン第2番、トロイメライ、ジムノペディ第1番が対象です。既存の入力譜・出典・ライセンスを引き継ぎ、主旋律の全発音と音高、曲長、テンポ、曲順、再生処理、保存済み音量を維持しています。

低音は原則C3〜C4、内声はF3〜E5の範囲で元の音名を保ってオクターブ配置します。同時発音の間隔・重複・直前の音からの移動を評価し、主旋律を優先します。移動後の同時同音は一つの櫛歯に集約し、伴奏の強さと音価に応じた減衰を調整します。主旋律には伴奏用の短縮減衰を適用しません。曲ごとに伴奏ゲインと下限を指定します。

低い櫛歯に控えめな整数倍音を加え、刺激の強い上部の金属モードを少し抑制しました。既存の解析合成器を使い、外部の音源・サンプル・サウンドフォントは読み込みません。MP3のデコード後に各曲を既存の-42 LUFS基準へ静的校正します。動的コンプレッサーは使いません。

上記を参考にした音域の選択、音の分離、余韻の設計は独自の判断です。他作品の編曲・録音・音色データは転用していません。

`node test-music-warm-arrangement.cjs` は音名、主旋律、低音域、重複、再現性、配信ファイルと検証データを確認します。`node test-roof-music-sequence.cjs` は全曲の順送り・クロスフェード・停止再開・音量保存を確認します。全長デコード、96kHz補間ピーク、境界、音量の結果は `assets/classic-music-v13/production.json` に保存します。`review.html` で新旧を同じ音量基準で比較できます。

iPhone実機の聴取と人による音色評価は未実施です。小型スピーカーの確認は汎用250Hzハイパス・4.5kHzローパスによる技術的な近似であり、機種固有の特性を再現しません。
