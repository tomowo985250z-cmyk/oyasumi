# 屋根のオルゴール6曲

対象は月の光、G線上のアリア、ノクターン第2番、トロイメライ、ジムノペディ第1番、月光ソナタ第1楽章。アヴェ・マリアを含む指定の7曲は選曲対象から外します。過去の素材・比較記録は保存します。

独自の櫛歯・木箱の合成器は `../music-box-expressive/synth.cjs` を再利用します。`voices.json` は共通の楽器らしさと曲別の余韻・強弱・テンポのレシピです。旋律の発音と伴奏を区別し、滑らかな同一の時間写像を全声部に使います。同時和音をばらさず、装飾音・原曲の音高・声部・発音数を維持します。余韻はノート末尾で切らず、循環する櫛歯の減衰と木箱反射でループをつなぎます。コンプレッサーや和声修正は使いません。

既存5曲は過去の入力譜面を再利用し、月光はStewart Holmes / Mutopia-276（Berners 1908、A. Winterberger校訂）の全第1楽章1142音を使用します。月光の入力譜面由来データ・独自編曲・派生録音はCC BY-SA 2.5です。作品自体はベートーヴェン作曲、入力譜面/MIDIに基づく浄書者の表示と派生物の条件を継承します。他曲の個別の条件は公開カタログに記載します。アプリコードや独立した合成器のライセンスを変更するものではありません。

参考作品の公開ページと説明を確認しました。参考録音そのものの聴取・波形解析を実施したとは記録しません。録音・編曲・音色データは使用していません。調整はユーザー指定の音質条件に基づく独自のものです。出典、レシピ、解析・再生検証は `assets/classic-music-v5/` と公開の出典ページに記録します。

配信前のPCMは十分なレベルで生成し、MP3の実測遅延・パディングを除外します。アプリには静的なゲイン補正だけを渡し、従来の静かな再生音量と自然音の混合を保ちます。音量設定、フェード、日替わり・手動選曲、ループの処理は変更しません。音声生成はオフラインで、画面描画の処理を追加しません。

空の出力先にWAVを再現できます。

```powershell
node test-support/music-box-elegant/render.cjs <新しい空の出力先>
```

## 音色のみの中間調整（v6）

786dd7eと直前の旧版5曲を比較し、`voices.json` の金属モード量・木箱共鳴/反射・減衰と二段階の配分だけを曲別に調整しました。基音の余韻は残します。音符・同時和音・装飾音・時間写像・速度・声部の強弱・配信用の固定ゲインは786dd7eと完全一致します。合成器とレンダー処理自体は変更しません。月光は旧版に未収録です。

履歴は上書きせず、配信は `assets/classic-music-v6/`。同フォルダの `review.html`、`comparison.json`、`production.json` に比較・技術検証を記録します。主観的聴感評価・実機確認は未実施です。
