対象は月の光、G線上のアリア、ノクターン第2番、トロイメライ、ジムノペディ第1番。アヴェ・マリア・月光ソナタを含む削除指定曲は選曲対象から外します。月光の音源と専用入力譜面は削除し、その他の過去の素材・比較記録は保存します。

独自の櫛歯・木箱の合成器は `../music-box-expressive/synth.cjs` を再利用します。`voices.json` は共通の楽器らしさと曲別の余韻・強弱・テンポのレシピです。旋律の発音と伴奏を区別し、滑らかな同一の時間写像を全声部に使います。同時和音をばらさず、装飾音・原曲の音高・声部・発音数を維持します。余韻はノート末尾で切らず、循環する櫛歯の減衰と木箱反射でループをつなぎます。コンプレッサーや和声修正は使いません。

5曲は過去の入力譜面を再利用します。個別の条件は公開カタログに記載します。アプリコードや独立した合成器のライセンスを変更するものではありません。

参考作品の公開ページと説明を確認しました。参考録音そのものの聴取・波形解析を実施したとは記録しません。録音・編曲・音色データは使用していません。調整はユーザー指定の音質条件に基づく独自のものです。出典、レシピ、解析・再生検証は `assets/classic-music-v5/` と公開の出典ページに記録します。

配信前のPCMは十分なレベルで生成し、MP3の実測遅延・パディングを除外します。アプリには静的なゲイン補正だけを渡し、従来の静かな再生音量と自然音の混合を保ちます。5曲の順番再生を繰り返し、曲間は約3秒のクロスフェード、♫で次曲へ進みます。音量保存・停止後の続きからの再開・夜の屋根だけという条件・自然音併用は維持します。音声生成はオフラインで、画面描画の処理を追加しません。

空の出力先にWAVを再現できます。

```powershell
node test-support/music-box-elegant/render.cjs <新しい空の出力先>
```
