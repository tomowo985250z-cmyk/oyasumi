# 4風景の物体露出検証

対象: 屋根・庭・寝室・障子部屋。朝7時、昼14時、夕18時、夜21時、375／390pxのWebKitで確認します。照明のある寝室・障子部屋はON／OFF、ごはん表示のある3風景は通常／食事中を確認し、閉じたカーテン・障子も追加確認します（計104条件）。

修正前は18時の固定区分で時計と照明器具だけが暗くなり、他の物体は太陽が沈む瞬間に消灯補正へ切り替わっていました。既存の `SolarModel.weights().night` を物体にも渡し、明度・彩度・照明器具の材質色を連続的に補間します。完全な昼と夜の既存露出は維持します。猫・器・ごはんは同じ補正を一度だけ適用し、距離・方向による既存の照明反射や投影、形状、配置、アニメーションは変更しません。

検証器は表示用の既存フィクスチャーだけを使い、外部通信を遮断します。修正前の2ファイルはGitの `cbdcb15` から読み込みます。全条件で形状・画像・座標・星空・操作部品・アニメーションを比較し、朝夕の太陽光源切替と18時境界、補正の累積、実際の照明切替も検証します。画像は実行時の出力先に保存し、配信には含めません。

```powershell
$env:OYASUMI_PLAYWRIGHT_PATH = 'C:/Users/智治/oyasumi/output/webkit-tools/core/package'
node test-support/scene-object-lighting/verify.cjs <検証結果の出力先>
```

屋根は昼間のアプリ上では非表示のため、朝昼は既存レンダラーの表示を検証します。昼の屋根を表示する機能や、屋根へのごはん・照明操作は追加しません。音声、星空、UI、操作処理は変更しません。

寝室の照明は既存仕様で夜間だけ操作可能です。朝昼夕の点灯不可状態を維持し、操作可能な夜間にON／OFFを実際に切り替えます。障子部屋は各時間帯のON／OFFを確認します。

検証条件は晴天・夏を基準にしています。実機Safariでの確認ではなく、Windows用WebKitエンジンによる表示確認です。結果は `verification.json` に記録します。
