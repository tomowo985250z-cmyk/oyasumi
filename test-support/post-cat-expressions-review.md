# 投稿に連動する猫アイコン

| 投稿 | 自動選択する表情 |
| --- | --- |
| 起きてるよ | おだやか / ごきげん |
| もう寝るよ | ねむそう / 寝顔 |
| まだ眠れない | そわそわ / きょとん |
| 眠れないけど寝てみる | あくび / ねむそう |
| 未投稿 | おだやか |

既存の「お先に寝ます」は「もう寝るよ」と同じ候補を使います。旧投稿で `post_intent` がない `awake` は「起きてるよ」として扱います。

`post-cat-expressions.js` が投稿IDと投稿の種類をハッシュし、候補から疑似ランダムに1つ選びます。DBのランダムな投稿IDが種になるため、投稿ごとに候補が分かれ、同じ投稿は全閲覧者・再読み込み・画面切替でも同じ表情です。プロフィールの手動設定・名前・猫種・役割は種に含めません。保存やlocalStorageへの追加書き込みは不要です。

タイムライン・公開プロフィールは表示対象の投稿を使い、マイページ・設定・猫種選択のプレビューは当日06:00以降の自分の最新投稿を使います。該当する自分の投稿がなければおだやかです。部屋の猫の寝姿・昼の行動・給餌アニメーションは既存の判定を続けます。

寝顔はユーザー承認済みの既存の閉じた目の画像を再利用します。通常は `face-calm.png` 相当を使い、マヌルは復元済みのおだやかアイコンを変えず、寝顔のときだけ既存 `cat-refresh-v1/manul/face-calm.png` を使います。画像ファイルは変更・生成していません。

手動表情選択のボタン・選択肢・保存ハンドラーを撤去し、猫種選択を維持しました。既存ダイアログのID／スタイルは猫種選択に再利用します。DBの `cat_expression` や既存RPC・データは変更しません。過去の手動設定は保存されたまま、新UIのアイコン判定には使いません。

## 検証

- `test-post-cat-expressions.cjs`：5,000件、全候補・分布・同じ投稿の固定・別実行環境との一致・手動値／猫種の影響なし・旧投稿・未投稿・既存画像・手動保存経路なし。
- `test-post-cat-expressions-browser.cjs`／`--edge`：各40条件（320・375・390・430px、投稿5種、両候補）。タイムライン・公開プロフィール・マイページ・設定の一致、再読み込み、マヌルを含む既存画像のdecode、未投稿、猫種の保存、06:00境界、手動表情の保存通信0件。本番の保存APIは実行せず、テスト用APIを使用。
- `test-profile-compact.cjs`／`--edge`：各10条件、320〜430px／568px高、情報・猫種／役割／ひとこと・設定・記録入口・専用おやつ導線・上限・アカウント切替。
- 遅延取得／再読み込み／復帰／アカウント分離の回帰：`test-cat-loading.cjs --focused`、`test-cat-startup-security.cjs`、`test-cat-startup-browser.cjs --focused`（いずれも `--edge` を含む）。監視する表情を新しい自動判定へ更新し、猫種・時刻・睡眠・未確定状態を隠すチェックは維持。起動テストは関連しない読取と遅い投稿者の取得をゲートで保留し、それらの完了を待たず表示することを検証します。Edgeの描画フレーム通知の遅れは変更前のcommitでも再現したため、固定の通信待ち時間との順序比較を避けています。
- 投稿／給餌の回帰：`test-home-post-choices.cjs`、`test-home-cat-care.cjs --interactions-only`（`--edge` を含む）。

画像と結果：`output/post-cat-expressions/local-webkit/`／`local-edge/`。公開後は `--published` で同じ画面テストを行えます。iPhone実機は未検証です。
