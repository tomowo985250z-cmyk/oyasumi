# 窓と屋根の月の同期

窓に固定で描いていた三日月を、屋根の既存計算 `RoofMoon` に接続した。29.530588853日周期、月相のパスと向き、時刻による位置・サイズの変化は共通。窓は既存の中心117／43・半径12を基準に座標を変換し、窓枠と桟の内側に収める。窓の既存色、屋根の色・透明度を保持。現在は光る輪郭だけのSVGアルファマスクで描画し、非発光部分は完全透明にしている。

両方を1つの1秒タイマーで同じ `NightClock.now()` の値から更新。非表示時は停止し、visibilitychange／pageshow／再読み込みで再計算する。屋根がない専用ごはん画面やプロフィールダイアログでも窓の月だけを更新する。SVG属性だけを更新し、部屋・猫・月のノードを毎秒置き換えない。画像追加・画像生成・DB変更なし。

`npm run test:room-moon`：1日分の軌道・サイズ比・月相共通性を検証。WebKit／Edgeの各80条件（320／375／390／430px × 通常／PWA相当 × 明暗テーマ × 18／21／00／03／05:59）で、月相・位置・サイズ、丸い窓枠と桟への非干渉を確認。共有タイマー、非表示停止・復帰、BFCache相当、再読み込み、窓だけの画面・ダイアログ、動きを減らす設定も確認する。

既存の屋根の月の各280配置、29.53日周期、06:00境界、猫の起動高速化・誤表示防止、給餌の6秒と重複防止も回帰検証。本番DBには接続しない。iPhone実機は未検証で、Safari／PWAの復帰はデスクトップWebKitで模擬している。
