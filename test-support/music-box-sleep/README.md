# 睡眠用オルゴール12曲の再調整

2026年11月4日。全12曲を既存の許諾済み譜面から再生成しました。参考録音の波形・演奏・MIDI・旋律の書き起こしは使っていません。既存録音は削除せず、新録音を `assets/classic-music-v3/` に置いてキャッシュを分離しています。

参考元・各曲2種類の公式試聴の比較数値・公開動画の評価情報・曲別のテンポ調整理由は [参考・調整記録](../../assets/classic-music-v3/review.html) と [詳細JSON](../../assets/classic-music-v3/references.json) に記録しています。原譜と各録音のライセンスは [カタログ](../../assets/classic-music-v1/catalog.json) と [出典ページ](../../assets/classic-music-v1/credits.html) を参照してください。

## 変更点

- 基音をA440の平均律、倍音を正確な整数倍に統一。デチューン、ビブラート、ランダムな発音時刻はありません。
- 高い倍音を弱め、1.7msの立ち上がり、音域に応じた減衰、控えめな木箱風共鳴・初期反射を使用。65Hzハイパスと3600Hzローパスで深い低音と高域の過剰な成分を抑制しています。
- 原譜の音高・音順・声部・強弱・相対リズム・ルバートを維持し、曲別の時間倍率のみを適用。すでに遅い「アヴェ・マリア」は少し流れを戻し、ほかは4〜18%ゆったりした時間軸にしました。
- 短時間の音量自動調整や強いコンプレッションを使わず、録音ごとの一定ゲインでK特性とゲート付き積分音量を従来12曲の中央値に合わせています。音量設定値、0%の扱い、フェード、選曲、保存処理は変更していません。

## 比較と検証

各曲2種類、計24件の公式公開試聴を約30秒ずつメモリ上でデコードし、スペクトル、強弱、エンベロープの周期性を比較しました。参考音声は保存・組み込みしていません。公開YouTubeの再生数・高評価数は検索取得時の人気指標として別に記録し、評価情報が少ない補足例も明示しています。全例が同じ評価方式で高評価と確認できたという意味ではありません。

周期性の候補は細分拍・倍速・半速にも対応するため、正確なBPMや残響時間として扱っていません。テンポ倍率は元譜と参考比較に基づく保守的な設計判断です。過去のCC0/CC BY実機録音の櫛歯・減衰分析も参照しましたが、録音環境やマイクの響きは分離できません。音源を複製せず、独立した合成パラメータのみを調整しています。

音響検証の既存結果：全12曲をネイティブでデコードし、24kHzのギャップレス境界と96kHzでの補間ピークを確認。積分音量の目標は約−42.293 LUFS、同じ測定系での曲間差は0.1 LU未満、最大音量の2曲重なりと自然音を保守的に合算しても約19.39dBの余裕があり、クリッピングはありません。基本音程・整数倍音・遅い余韻の抑制・音量測定のゲイン直線性も検証済みです。

K特性と400msブロック/100msホップ、−70LUFS絶対ゲート/−10LU相対ゲートの係数は [EBU](https://tech.ebu.ch/loudness/) と [libebur128](https://github.com/jiixyj/libebur128/blob/master/ebur128/ebur128.c) の式で照合しています。1kHz正弦波の校正と振幅変更の直線性を確認していますが、認証済み計器による測定ではありません。睡眠効果を保証するものではなく、主観的な試聴・iPhone等実機での聴感確認は未実施です。

## 再現用の入力と合成

`scores.json` は音高・時刻・強弱を含む従来の入力イベントと出典を保持しています。譜面由来データと各派生音源はカタログに記載された元の版の条件（CC BY / CC BY-SA / PD等）を維持します。この条件をアプリコードやほかの素材に拡張するものではありません。

`synth.cjs`、`mastering-config.json`、`loudness.cjs` はオフライン専用で、アプリには読み込ませません。`render-wav.cjs` は指定した空の出力先へWAVと生成メタデータを書きます。今回の作業の再開にあたって音声生成・調査・音響解析を繰り返す必要はありません。

```powershell
node test-support/music-box-sleep/render-wav.cjs <新しい出力ディレクトリ>
```

配信用のMP3は既存と同じLAMEJSのモノラル24kHz・96kbpsでオフライン符号化し、実測したギャップレス境界と一定ゲイン補正をカタログへ反映しています。ランタイムの音声ライブラリ追加はありません。
