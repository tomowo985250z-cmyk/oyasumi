# 自然音 第1段階（2026-10-22）

- 操作は「設定 → 自然音」に追加。初期OFF、初期音量25%。新しい端末保存キーは `oyasumi-nature-sounds-v1` のみ。
- 実録音のそよ風・雨・虫の声・日本の風鈴を使用。BGM・合成音・外部音声サービスは使用しない。
- 縁側が表示されている場合だけ再生する。雨天は雨音、雨以外はそよ風。夏・秋の夜は虫の声を重ねる。判定は既存の `DayRoom.world()` / `SolarModel.phase()` を利用。
- 風鈴は雨以外の夏に45〜90秒間隔で単発再生。夜はさらに控えめにする。
- 環境切替は1.4秒、音量とOFFは短いフェード。OFF後は音源を停止しAudioContextを休止する。
- 非表示・ページ離脱時は停止。復帰後はユーザー操作で再開する。保存ONでも再読み込み直後には再生しない。
- AudioContextの生成・resumeは信頼された操作内で行い、その後に音声を取得・デコードする。取得中のOFFや環境変更後に古い取得結果が鳴り始めないよう世代を照合する。
- 音声コードは低優先度の非同期取得。コード取得待ちを意図的に発生させても猫とホームを表示できることを確認した。初期音声リクエストは0件。
- 音声は合計786,672バイト。音声ファイルは使用時だけ取得し、風鈴は鳴るタイミングまで取得しない。
- 障子の開閉と音の変化は連動させない。猫・障子の操作と既存の部屋設定の保存値を維持する。

## 素材と利用条件

4素材とも元の配布ページにCC0 1.0を確認。作者・原音URL・加工内容・ハッシュは [素材の出典](../assets/nature-sounds-v1/README.md) と [manifest](../assets/nature-sounds-v1/manifest.json) に記録した。

## 検証

`npm run test:nature-sounds` はEdgeの実音声検証とWebKitの画面検証を行う。

- Edge / 320・375px：実際のMP3デコードと音声出力、ON/OFF、読み込み中のOFF、音量とON設定の復元、季節・夜・天候切替、夏限定の風鈴、非表示時の停止、猫タップ、障子全開閉、既存部屋設定の不変を確認。
- Windows版WebKit / 320・375px：表示、横はみ出しなし、初期OFF、音量復元、音声非対応時の案内を確認。この検証用ビルドにはAudioContext自体がないため、WebKitで実音声を検証したとは扱わない。
- iPhone Safari実機での再生・音質確認は未実施。操作内でのresumeは [Web Audio APIの公式リファレンス](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices) に従う。
- 全ブラウザ検証はAPIをローカルfixtureに置換し、外部通信を禁止。本番DBへの書き込み0件。
