# 月の移動・更新調査（2026-10-15）

窓・屋根とも時間経過で移動し、位置・月齢・マスク形状は同期していた。移動停止やマスク修正による更新不良は再現しなかった。アプリ本体の計算・更新処理は維持し、時計とタイマーを差し替えずに動作を確認する回帰テストを追加した。DB変更なし。

## 現在の計算

`roof-cats.js` の `RoofMoon.snapshot()` が共通の計算元。位置はJST時刻による装飾用の24時間軌道で、時・分・秒・ミリ秒を使う。

```text
theta = (JST時刻 - 18) / 24 * 2π
roofX = 192 + 2.5 * (1 - cos(theta))
roofY = 26 - 11 * sin(theta)
scale = 1.025 + 0.125 * cos(theta - 0.7)

windowX = 117 + (roofX - 194.5) * 2
windowY = 43 + (roofY - 26) * 0.65
```

屋根の描画倍率は `7.5 * scale`、窓は `12 * scale`。窓と屋根は異なるSVG座標系なので、数値を一致させず上記の対応関係を検証する。月齢は `2000-01-06T18:14:00Z` を基準とした29.530588853日周期。日付や06:00で月齢・軌道をリセットしない。

## 更新・復帰・マスク

- `app.js` の `syncRoofMoon()` が1つの `NightClock.now()` を読み、表示中の窓と屋根をまとめて更新する。次回の `setTimeout` は1000ms後。ネットワーク取得や流れ星の発生を待たない。
- `NightClock` はサーバー時刻に `performance.now()` の経過分を加える。同期後の端末時計・端末タイムゾーンの変更では軌道が飛ばない。
- 非表示中は月専用タイマーを止める。`visibilitychange` と `pageshow` で現在時刻から即時に再計算し、その後も1秒更新を継続する。バックグラウンド滞在時間分のアニメーションを再生する処理はない。
- 30秒ごとの部屋同期や15分ごとの猫の再描画でもSVGが更新されることがある。これは月専用タイマーと別の処理。月の通常の1秒更新は既存の月・マスク・パス・猫ノードを保持する。
- SVGマスクの輪郭 `d` と向きも毎回更新し、月全体の `transform` で光る面とマスクを一緒に移動する。通常更新中のマスクIDと参照は維持され、再描画後も参照先が有効。黒い円は追加しない。

軌道の移動量は小さい。例えば屋根の21:00→22:00はSVG座標で横約0.52、縦約1.75。表示倍率1.2倍では約0.62px・2.10pxで、数秒見ただけでは止まって見える程度の速度になる。

## 検証方法

`npm run test:moon-motion`：単体計算と、新しい `test-moon-motion.cjs` をWebKit／Edgeで実行する。

新テストはPlaywrightの仮想時間で `Date`・`performance`・ブラウザタイマーを進める。アプリの `NightClock.now()` と `RoofMoon` の計算は維持し、`RoofMoon.update()` を委譲ラッパーで観測する。初回1秒で2つの月が同時に更新され、続く発火間隔が1000msであることを測定。通信を未完了に保ち、1秒・1分・30分・1時間後、非表示から1時間後の復帰、BFCache相当で30分後の復帰、復帰後の次の1秒も確認する。端末時計を2040年に変えてもサーバー基準の月が飛ばないことも確認する。

各エンジン16条件：320／375／390／430px × 通常／PWA相当 × 動きを減らす設定の有無。各条件11回の座標・位相・マスク参照を記録し、表示時の更新遅れが1秒以内であることを検証する。公開版も同じ新テストで確認する。

既存の `test-room-moon-browser.cjs`（各エンジン80条件）と `test-roof-moon-browser.cjs`（各280配置）で、明暗テーマ、0〜3匹、窓枠・桟・猫との非干渉、横はみ出し、共有タイマー、復帰・再読み込み、窓だけの画面、ダイアログ、06:00境界を回帰確認する。

実行レポートは `output/moon-motion/{local-webkit,local-edge,published-webkit}/report.json`。ブラウザではAPIを隔離し、本番DBへの接続・書き込みは行わない。iPhone実機での検証は含まず、WebKitでモバイル表示・PWA・復帰イベントを模擬する。
