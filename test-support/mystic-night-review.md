# 寝室・障子部屋・庭の夜景（2026-11-04）

基準: ac94692。既存の素材だけを使い、空の色・星の描き方・遠景の色補正を調整。

- 黒に近い紺色と地平線の薄い霞。既存の霞用矩形をグラデーションに変更。
- 微細な星の径・明暗差を調整し、天の川の雲状のにじみを抑制。
- 遠景は既存の色行列で暗さと淡い青い空気感を調整。室内灯の反射時は星を少し抑える。
- 障子を閉じると星・天の川を非表示。障子紙・照明・月の既存処理は維持。
- 星表・投影式・方角・時刻・星数・星の座標・月の位置は変更なし。猫・家具・建物・操作・音声も変更なし。
- 描画用の画像、フィルター、アニメーション、タイマー、星のパスは追加なし。追加DOMはグラデーション定義4要素のみ。

## 検証

ローカルAPIフィクスチャで変更前と比較。本番へのデータ書き込みなし。
検証スクリプト・画像・JSONは作業領域 `output/mystic-night-v1/` に保存。

- Edge / WebKit: 各38条件。320 / 375 / 430px幅、照明ON/OFF、障子・カーテン開閉、四季、月明かりの異なる夜、昼夕、屋根。
- 猫の画像・位置・大きさ、家具、主要星の座標・径、微細星パス、月の位置・位相、方角が変更前と一致。横あふれなし。
- 昼夕・屋根の描画DOMはIDを正規化して一致。PNGは同一でない場合あり（既存の紙目のラスタライズ差）。
- 閉じた障子の星と天の川は不可視。照明ONの星減光、OFFの反射解除、曇天・雨天の星減光を確認。
- 既存フィルター数・アニメーション数は同じ。既存のキャッシュ済み空更新処理も比較。
- キャッシュ済み更新の中央値: Edge 1.29→1.26ms。WebKitの初回は2.2→2.6msと変動したため、100回更新×10組を前後交互に再測定して1.960→1.945ms。ローカルPC上の処理時間であり、実機FPSを示す値ではない。
