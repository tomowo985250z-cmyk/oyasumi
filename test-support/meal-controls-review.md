# 猫のごはん：操作表示の整理

「ごはんだよ」「カリカリ」を保持し、自分のごはんのカリカリだけ囲み枠を削除。未給餌時の操作ボタンは高さ56px以上、給餌済みはボタンを持たない完了文と次回時刻に変更した。「残り0回／1回」と成功メッセージの重複をなくし、エラーやおやすみ中の説明は残した。届いたおやつの履歴、他の猫へのおやつは維持。

次回時刻は既存の `CatCare.nextBoundary()` から表示する。朝の給餌後は今日12:00、夜は翌6:00、日付が変わった後は今日6:00。給餌済みでおやすみ中なら、昼の回数リセットでは起きないため、既存のおやすみ解除時刻である翌6:00を案内する。旧方式の記録では既存の0時リセットを使用。古い時間枠の記録では完了や次回時刻を出さず、確認中の無効ボタンに戻る。

変更は `cat-care.js` の表示生成と `style.css`。給餌API、ロック、回数制限、リセット時刻、6秒のアニメーション処理、画像・DBは変更していない。

## 検証

- `npm run test:cat-meal-controls`：WebKit／Edgeで各64条件（320／375／390／430px × 明暗テーマ × 朝・昼・夜・日付変更後 × 給餌前後）。操作ボタン、控えめな完了表示、次回時刻とJSTの日付、枠なしカリカリ、重複文言・横はみ出しを確認する。おやすみ済み、時間枠切り替え前後、保存確認エラー、他猫のおやつも確認する。
- `npm run test:home-cat-care`：各エンジン72画面条件、64の猫種・幅の組み合わせで3段階のアニメーション。自然な6秒再生、朝6時・昼12時の制限切り替え、二重送信防止、失敗からの再試行、画面移動・低速画像・バックグラウンド復帰、動きを減らす設定を確認する。完了ボタンを期待していた箇所は静的な完了表示を確認するよう更新した。

`test-cat-meal-controls.cjs --published` で公開版の画面も同じ条件で確認できる。スクリーンショットとJSONレポートは `output/cat-meal-controls/` に保存し、`meal-before-after-375.png` に朝・夜の給餌前後を並べる。APIはテスト用に隔離し、本番DBへの接続・書き込みは行わない。iPhone実機は含まず、モバイル幅のWebKit／Edgeで検証する。
