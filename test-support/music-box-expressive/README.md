# 曲別のオルゴール再調整

2026年11月4日。旧版は保存したまま、新版を `assets/classic-music-v4/` に置きます。[比較と調整記録](../../assets/classic-music-v4/review.html) から全12曲の過去3版と新版を切り替えて確認できます。[前回の参考調査](../../assets/classic-music-v3/references.json) は履歴として保存し、今回の音づくりの制限には使いません。

旧版の整数倍音固定、デチューン制限、全曲共通の65Hz/3600Hzフィルター、減衰上限、一律の音域別強弱・平方根圧縮、66BPM上限と追加減速を解除しました。原譜由来の和音・不協和音や音符を間引く処理はありません。月の光は既存の冒頭抜粋・終止和音・独自抑揚を保ちます。他11曲は旧変換を逆算し、譜面由来のMIDI強弱を復元しています。

`voices.json` の曲別の数値は音づくりの個別選択で、共通の許容上限ではありません。非整数倍の金属モード、微細な音程差とゆっくりした揺れ、二段階の減衰、木箱共鳴・反射、低音と旋律のバランスを曲ごとに設定します。声部や不協和音の判定・削除・自動修正はしません。音量は曲別の静的ゲインのみで、共通LUFS目標や動的コンプレッサーはありません。配信用 `level` はMP3符号化による減衰だけを補正します。

保護する技術条件は非数・クリッピング・エイリアシング・ループの不連続・デコード失敗です。音色の好ましさ、デチューン量、残響、テンポ、強弱の許容値をテストの合否条件にしません。原譜イベントの音高・声部・相対リズム・発音数と強弱復元を `verify-scores.cjs` で確認します。

既存v1/v2/v3の解析結果を再利用して比較し、新版だけをネイティブデコードで測定します。24kHzの実測MP3遅延とループ範囲、96kHz補間ピーク、自然音と曲切替が重なる際の余裕を確認。聴感の主観評価・iPhone等実機での確認は未実施です。参考録音の波形は使用していません。出典・派生録音のライセンスは従来カタログの条件を継承します。

再現は既存音源を上書きしない空の出力先で行います（オフライン、Node組込みAPIのみ）。

```powershell
node test-support/music-box-expressive/verify-scores.cjs
node test-support/music-box-expressive/render-wav.cjs <新しい空の出力先>
```

配信形式は従来どおりモノラル24kHz、月の光は16bit WAV、他11曲はLAMEJSで96kbps MP3。アプリ側は曲配列のURL・ループ・符号化補正値だけを更新し、選曲・音量設定・フェード・保存・自然音の実装を変更しません。最終の技術検証と再生回帰の記録は `verification.json` に保存します。
