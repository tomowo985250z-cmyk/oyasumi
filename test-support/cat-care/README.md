# 猫のごはん・おやつ ローカル確認

`node test-support/cat-care/serve.cjs` を起動して http://127.0.0.1:9390/ を開く。
Node 22 と package.json に記載の PGlite が必要。メモリ内の検証DBのみを使い、本番Supabaseには接続しない。終了時に検証データは消える。

- ごはん：日本時間の当日に「おやすみ」「寝てみる」「早めに寝る」を投稿した自分の猫へ1回。連続投稿は不要。
- おやつ：贈る側が日本時間の1日につき合計1回。他の猫限定。
- 届いたおやつ：本人に今日・累計と直近30日分の受取日別記録を表示。全日付の記録は保持。贈り主情報をクライアントに返さない。
- テーブルは直接読み書き不可。認証済みRPC内で権限・投稿条件・重複を検査。
- 約3秒の無音CSSアニメーションは承認済みPNGを再利用。ごはんとおやつはお皿の中身のみ変更。動きを減らす設定では短い静止表示。

検証：`node test-cat-care-sql.cjs`、`node test-cat-care-browser.cjs`。結果は `output/cat-care-v1/`。ブラウザ検証にはローカルサーバーとEdgeが必要。

本番DBへの追加SQL適用、commit、push、公開は未実施。承認後に `supabase/cat-care.sql` を適用するまでは追加UIは表示されず、既存機能を継続する。既存DBのテーブル・データ・7日制限解除設定を変更するSQLは含まない。
