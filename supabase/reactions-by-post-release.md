投稿ごとのリアクション4択（16種類）と、翌朝の合計・開閉する内訳を追加します。

- `reactions-by-post.sql` を既存の本番プロジェクトのSQL Editorで適用してから、画面を公開します。トランザクション内で実行され、再実行できます。
- `oyasumi_posts.post_intent` は追加の意味情報です。`choice` は従来のままなので、起きている2択は睡眠回数・人数・ごはん条件を増やしません。
- 旧投稿には意味情報を後付けしません。区別できない過去の `awake` は従来の「起きてるよ」表示・通常の起床中4択とし、保存済みの旧リアクションは元のラベルで別途表示・取消できます。
- 旧4種類の保存値と既存RPCは維持します。新しい16種類を旧種類へ読み替えて保存することはありません。
- 投稿は既存どおり、本人ロック・同じ内容の60秒以内の重複防止・1分10件制限を使用します。起床中の2択を切り替えたときは別投稿として残します。
- リアクションは既存RPCの認証・公開範囲・本人ロック・1投稿1人1件の置換・取消を引き継ぎます。自己リアクションの可否も既存どおりです。
- 朝は既存の画面表示条件（前夜の睡眠報告、06:00～12:00等）を維持します。本人の昨夜の全投稿に届いたリアクションを合計し、自己リアクションを除外します。タイムラインの3時間表示期限は朝の集計を削りません。
- 0件はカードごと非表示です。取得失敗を0件として表示しません。開いた内訳は自動更新でも開いた状態を保ちます。
- 猫画像・6秒演出・お世話・プロフィール・昼画面のカード非表示・7日制限解除のSQLは変更しません。

検証: `npm run test:reactions`（隔離API、PGlite、WebKit）。Edgeは `node test-reactions-browser.cjs --edge`。本番データへテスト投稿は作成しません。
