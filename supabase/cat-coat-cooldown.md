# 猫種の7日制限

`cat-coat-cooldown.sql` を `wild-cats.sql` と `profile-setup.sql` の後に適用する。既存の猫種・プロフィール・投稿・画像を更新せず、既存ユーザーは導入後の最初の保存から制限を開始する。新規ユーザーは初回選択をすぐ保存できる。同じ猫の再送は期限を延長しない。

7日はサーバー時刻で168時間。変更履歴は非公開の専用テーブルに保存し、プロフィールの猫種更新トリガーで既存RPCからの変更も拒否する。クライアントは自分の期限だけを取得する。取得できない場合は猫種選択を無効にし、他の機能は継続する。期限は日本時間でマイページに表示する。

30日制限からの更新も同じSQLを再適用する。記録済みの変更日時は更新せず、次回変更可能日時とDB/RPCの拒否判定を「変更日時＋168時間」に短縮する。既存ユーザーも直ちに7日基準になり、7日経過済みなら変更できる。期限内エラーのコード`P0030`は既存クライアントとの互換性のため維持する。

通常猫8種類・野生猫4種類が対象。名前・表情・職業・ひとことなどの更新は制限しない。

検証：`npm install` 後 `npm run test:cat-coat-cooldown`。PGlite上でSQLを実行し、初回保存、導入時の既存行保持、期限前後、同一猫再送、全12種類、RPC・直接更新・日時改ざんの拒否を確認する。ブラウザテストは共有データを固定し、4幅のマイページ表示と初回選択、期間中の無効化、期限後の選択を確認する。本番データは変更しない。

ライブテストは猫種ごとに別のテストユーザーを使い、制限を迂回しない。実DBの168時間の期限は`test-cat-coat-cooldown-live.js`で確認する。30日から7日への移行と既存変更日時の保持はローカルSQLテストで確認し、本番ユーザーの変更日時は操作しない。
